# База данных онлайн публикаций

Django-приложение для создания, публикации и управления постами с системой категорий и комментариев.

## Установка и запуск

### 1. Создать виртуальное окружение

```bash
python -m venv venv
```

### 2. Активировать виртуальное окружение

```bash
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Настроить переменные окружения (опционально)

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Переменные окружения для разработки (по умолчанию):

```env
# Секретный ключ Django (для разработки)
DJANGO_SECRET_KEY=django-insecure-b82cpf!gu4xkpr-$gq4&lzm*yxhr65@t!)k+rz#w0rkif%2hbu

# Режим отладки (True для разработки)
DJANGO_DEBUG=True

# Разрешенные хосты (для разработки)
DJANGO_ALLOWED_HOSTS=localhost,127.0.0.1
```

**Для продакшена:**
- Сгенерируйте новый `DJANGO_SECRET_KEY`
- Установите `DJANGO_DEBUG=False`
- Укажите ваши домены в `DJANGO_ALLOWED_HOSTS`

### 5. Применить миграции

```bash
python manage.py migrate
```

### 6. Создать суперпользователя

```bash
python manage.py createsuperuser
```

Следуйте инструкциям для создания администратора.

### 7. Запустить сервер разработки

```bash
python manage.py runserver
```

Приложение будет доступно по адресу: http://127.0.0.1:8000/

Админ-панель: http://127.0.0.1:8000/admin/

## Переменные окружения

| Переменная | Описание | По умолчанию |
|-----------|----------|--------------|
| `DJANGO_SECRET_KEY` | Секретный ключ Django | `django-insecure-...` (только для разработки!) |
| `DJANGO_DEBUG` | Режим отладки (True/False) | `True` |
| `DJANGO_ALLOWED_HOSTS` | Разрешенные хосты (через запятую) | `localhost,127.0.0.1` |

**Важно:** Для продакшена всегда генерируйте новый SECRET_KEY:

```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

```

│   ├── forms.py       # Формы для постов

│   ├── urls.py        # URL-маршруты блога
│   ├── admin.py       # Регистрация моделей в админке
│   └── templates/blog/
├── users/             # Приложение для пользователей
│   ├── views.py       # Регистрация, профиль
│   ├── forms.py       # Формы регистрации
│   ├── urls.py        # URL-маршруты пользователей
│   └── templates/users/
├── comments/          # Приложение для комментариев
│   ├── models.py      # Модель Comment
│   ├── views.py       # Добавление комментариев
│   ├── forms.py       # Формы комментариев
│   ├── urls.py        # URL-маршруты комментариев
│   └── admin.py       # Регистрация моделей в админке

│   ├── settings.py    # Настройки Django

└── templates/         # Общие шаблоны
    └── base.html      # Базовый шаблон
```

## Основные функции

- Создание и просмотр постов
- Категоризация постов
- Комментирование постов (для авторизованных пользователей)
- Поиск постов
- Регистрация и аутентификация пользователей
- Пагинация списка постов
- Админ-панель для управления контентом

## Технические детали

- Django 5.1.15
- SQLite база данных
- Использование встроенной модели User
- CSRF защита
- Использование get_object_or_404() для безопасного получения объектов
- Оптимизация запросов с select_related() и prefetch_related()
- Функция get_published_posts() для фильтрации опубликованных постов

## URL-маршруты

- `/` - Главная страница со списком постов
- `/post/<id>/` - Детали поста с комментариями
- `/post/create/` - Создание нового поста (требует авторизации)
- `/category/<id>/` - Посты определенной категории
- `/user/<id>/` - Посты пользователя
- `/search/` - Поиск постов
- `/login/` - Вход
- `/logout/` - Выход
- `/register/` - Регистрация
- `/profile/<id>/` - Профиль пользователя
- `/admin/` - Админ-панель
